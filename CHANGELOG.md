# Изменения

## 0.3.0

- Лаунчер переименован: LinFix → **OnlineFix-Launcher**. Библиотека, настройки и загрузки сохраняются.
- В окне игры в каталоге — кнопка «Страница в Steam» (вместо ссылки на FreeTP).
- Новый, понятный README.
- На Windows новая версия ставится в папку «OnlineFix-Launcher»; старую установку «LinFix» можно удалить через «Установка и удаление программ».

## 0.2.0

- Языки интерфейса: українська, русский, English, Deutsch, Polski, Español. Выбор — в «Настройки → Оформление» и на первом шаге мастера; по умолчанию — язык системы.
- Даты, размеры и время показываются в формате выбранного языка.

## 0.1.0 — первый релиз

- Каталоги FreeTP и Online-Fix во вкладках; поиск, «Популярные», «Топ-100», сортировка по размеру и дате, обложки.
- Встроенный торрент-клиент (librqbit), продолжение загрузок после перезапуска.
- Установка через Proton в отдельном префиксе, выбор exe, папка для каждой игры.
- Онлайн-фиксы FreeTP: автоматическая установка, выбор варианта, фиксы-установщики Inno Setup, загрузка через встроенный браузер, если сайт закрыт Cloudflare.
- Проверка обновлений игр и фиксов, обновление поверх с сохранением префикса.
- Запуск через Spacewar (480) с оверлеем Steam (Shift+Tab), umu-launcher по желанию, скачивание GE-Proton.
- Поддержка разделов NTFS / exFAT (префикс в домашней папке).
- Мастер первого запуска, Material Design 3 с динамическим цветом, светлая / тёмная / системная тема.
- Автообновление лаунчера через GitHub Releases.
- Windows: запуск без Proton.
